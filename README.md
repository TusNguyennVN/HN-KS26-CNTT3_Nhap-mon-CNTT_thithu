# Văn Phòng Phẩm Website

Dự án **quản lý cửa hàng văn phòng phẩm** được xây dựng để
*hỗ trợ tổ chức dữ liệu và theo dõi đơn bán*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| docs | Chứa tài liệu nhập hàng |
| media | Chứa hình ảnh logo |
| data | Chứa bảng tính đơn bán |
| logs | Chứa file log và báo cáo |
| backup | Chứa bản sao lưu logo |

## Lệnh sử dụng

```powershell
Get-ChildItem -Force -Recurse
```
